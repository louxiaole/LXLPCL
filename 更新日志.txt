## 🔥 v1.0.0（2026.10.29）— 首个正式版

### 🆕 新增功能

- **全新「汉化」页面** — 侧边栏新增汉化入口，分「Mod 汉化」与「整合包汉化」两个模块，先选择已下载的版本 / 整合包，再看全部条目或按 Mod 列表逐个查看
- **语言文件对比与缺失统计** — 读取模组 jar 内 `assets/<命名空间>/lang/en_us.json` 与 `zh_cn.json` 逐键对比，区分「已汉化 / 同原文 / 缺失」，列表显示覆盖率（如 `4/6（66%）`）
- **筛选支持「未汉化」** — 模组列表提供 全部 / 有汉化 / 有缺失 / 未汉化 四种筛选，未汉化指有原文但完全没有中文语言文件的模组
- **缺失条目可直接补译并保存** — 详情窗口「汉化」列即点即改，保存后写入 `LXLPCLData/translations/<版本>/<模组>.json`，并自动生成资源包 `resourcepacks/LXLPCL汉化.zip`（含 `pack.mcmeta` 与合并后的 `zh_cn.json`），进入游戏启用即可生效
- **无内置汉化的模组同样可编辑** — 完全没有 `zh_cn.json` 的模组不再禁止编辑，保存时会为其新建对应命名空间的语言文件
- **识别非语言文件的文本来源** — 支持统计 Patchouli 手册（`patchouli_books/<手册>/<语言>/*.json`）、AE2 指南（`ae2guide/**.md` 与 `_zh_cn.md` 配对）、FTB 任务（`config/ftbquests/quests/lang/*.snbt`）等不在 lang 文件中的文本，并在详情窗口逐文件显示已汉化 / 缺失
- **GitHub Release 自动更新** — 启动时请求最新 Release（失败时回退到仓库根目录 `version.json`），比较版本号后弹出更新窗口；确认后下载整包、退出后由批处理解压覆盖并自动重启，同时备份 / 恢复配置
- **关于页新增更新入口** — 提供「检查更新」「GitHub 仓库」「下载最新版本」按钮
- **整合包导出 / 导入** — 版本文件与可选模组、配置、存档、资源包、光影打包为 zip；导入兼容 LXLPCL / PCL2 / HMCL 结构，重名自动改名
- **版本与账户体系** — 原版与 Fabric / Forge / NeoForge 等加载器安装、微软正版 / 外置登录 / 离线账户、Java 自动匹配与下载
- **Modrinth 模组下载** — 模组介绍自动翻译中文，详情页一键跳转
- **皮肤编辑器** — 图层系统、3D 模型预览、行走模拟（WASD / 空格跳跃）、我的皮肤库
- **联机功能** — 局域网与樱花映射一键连接

### 🔧 问题修复 & 优化

- 汉化扫描改为后台线程执行并显示进度，切换版本时自动取消上一次扫描
- 模组列表启用虚拟化回收，数千条条目滚动不卡顿
- 汉化补丁按版本计算资源包路径，隔离目录的整合包写入 `versions/<版本>/resourcepacks/`，确保游戏内能看到
- 修复补丁包重复生成时覆盖旧内容的问题，改为合并已有 zip 中的语言数据

## 发版流程

1. 修改 `LXLPCL/LXLPCL.csproj` 中的 `<Version>`
2. 运行 `build-release.ps1`，自动发布、打包并备份到 `LXLPCL-releases/v<版本>/`（含 `SHA256.txt` 与 `version.json`）
3. 在 GitHub 创建同 tag（如 `v1.0.1`）的 Release，上传生成的 `LXLPCL-v<版本>-win64.zip`
4. 同步更新仓库根目录 `version.json`
5. 在本文件顶部追加对应版本的更新日志
